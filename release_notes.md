# Release Notes - v0.2.0

Esta release consolida a transição de documentações cruciais para o inglês e promove um renomeamento semântico de alguns dos principais workflows da Antigravity IDE, visando maior consistência com o ecossistema e clareza para a comunidade global.

## 🚀 Features

* **Workflow de Release (`/release`)**: O antigo gatilho `/changelog` foi modernizado para `/release`, alinhando-se à orquestração de entregas e geração de tags.
* **Workflow de Vitrine (`/readme-projeto`)**: O antigo gatilho `/readme` (Developer Advocate) foi refatorado para `/readme-projeto` para maior precisão de escopo.
* **Internacionalização Parcial**: Todos os arquivos `README.md` (internos) e as diretrizes/instruções dos templates (`template_planejamento.md`, `template_artefatos.md`, `template_doc_diretorio.md`, `template_grafo.md`) foram traduzidos para o inglês, padronizando a documentação estrutural, embora mantendo a geração dos relatórios de negócio em português.
