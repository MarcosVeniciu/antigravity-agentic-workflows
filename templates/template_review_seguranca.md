## How to Audit
Focus on how data enters (interfaces, HTTP parameters) and how it interacts with external services (DB, OS). Be highly suspicious of loose validations done via `if` instead of strict Schemas.

---

## 1. Injection Prevention (OWASP A03:2021)
**How to Measure:** Search for string formatting or concatenation applied to Database or OS calls.

- [ ] **SQL/NoSQL Injection:** Is the database query generated by concatenating strings or f-strings with user parameters instead of using ORM parameterized queries?
- [ ] **Command Injection:** Are there `subprocess` or `os.system` modules passing untreated variables directly to the terminal?
- [ ] **Path Traversal:** Do file system operations validate paths against `../` directory traversal?
- **How to Handle:** Order the swap of concatenation for strict ORM parametrization. For OS calls, require safe lists in `subprocess.run()` without `shell=True`.

## 2. Authentication & Authorization (OWASP A01/A07:2021)
**How to Measure:** Check route decorators, middleware, and database lookups for resource access.

- [ ] **Endpoint Protection:** Do protected endpoints require valid tokens/sessions before processing logic?
- [ ] **IDOR (Insecure Direct Object Reference):** Are resource IDs validated against the currently authenticated user's ownership before returning data?
- [ ] **Rate Limiting:** Do sensitive endpoints (login, password reset) have protection against brute force?
- **How to Handle:** Demand the implementation of auth dependencies/decorators on routes. For IDOR, ensure queries include `user_id = current_user.id`.

## 3. Strict Input Validation & Serialization (OWASP A08:2021)
**How to Measure:** Look at the first lines of the controller/route where user payloads arrive.

- [ ] **Schema Bypass:** Does the API receive raw dictionaries from the user and pass them to internal services without validating against a strict contract (e.g., Pydantic, Marshmallow)?
- [ ] **Dangerous Deserialization:** Does the code execute `pickle.loads` or `yaml.load(loader=UnsafeLoader)` on external payloads?
- **How to Handle:** Order the creation of a strict Schema (with string length limits and regex) to replace raw dicts. Swap unsafe loading libraries for safe `.json()` parsing.

## 4. Secret Management & Configuration (OWASP A05:2021)
**How to Measure:** Look for string literals containing keys, and check logging outputs.

- [ ] **Hardcoding:** Are there passwords, API keys, JWT tokens, or cloud service credentials directly in string format or as default input variables?
- [ ] **Log Sanitization:** Do logs print raw payloads that might contain passwords, tokens, or PII (Personally Identifiable Information)?
- **How to Handle:** Demand that secrets strictly come from `os.getenv()` or a secrets manager, failing if missing. Mask sensitive fields in logging configurations.

## 5. Cryptography & Dependencies (OWASP A02/A06:2021)
**How to Measure:** Check password handling functions and dependency manifest files.

- [ ] **Password Hashing:** Are passwords stored using strong hashing algorithms (e.g., bcrypt, argon2) rather than plaintext or MD5/SHA1?
- [ ] **Data in Transit:** Do sensitive tokens or PII travel via URL query strings instead of secure headers/body?
- [ ] **Version Pinning:** Are production dependencies pinned to exact versions to prevent supply chain attacks?
- **How to Handle:** Order the implementation of proper hashing libraries. Move query string secrets to headers.
