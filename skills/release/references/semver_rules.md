# Semantic Versioning Rules (SemVer 2.0.0)

Given a version in format **MAJOR.MINOR.PATCH** (e.g., `1.4.2`):

1. **MAJOR (1.0.0 ➔ 2.0.0)**:
   * Incremented when code changes introduce **breaking changes** or alter public API signatures.
2. **MINOR (1.4.0 ➔ 1.5.0)**:
   * Incremented when backward-compatible **new features** are added to the system.
3. **PATCH (1.4.2 ➔ 1.4.3)**:
   * Incremented when only backward-compatible **bug fixes** or pure structural refactorings occur.
