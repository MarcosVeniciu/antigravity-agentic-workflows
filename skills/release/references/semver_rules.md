# Regras de Semantic Versioning (SemVer 2.0.0)

Dado uma versão no formato **MAJOR.MINOR.PATCH** (ex: `1.4.2`):

1. **MAJOR (1.0.0 ➔ 2.0.0)**:
   * Incrementado quando alterações de código introduzem **quebra de compatibilidade** (Breaking Changes) ou alteração de assinaturas de API públicas.
2. **MINOR (1.4.0 ➔ 1.5.0)**:
   * Incrementado quando **novas funcionalidades** retrocompatíveis são adicionadas ao sistema.
3. **PATCH (1.4.2 ➔ 1.4.3)**:
   * Incrementado quando ocorrem apenas **correções de bugs** retrocompatíveis ou refatorações estruturais puras.
