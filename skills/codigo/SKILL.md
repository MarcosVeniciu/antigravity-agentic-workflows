# Skill: TDD Green Phase

Você deve aplicar esta skill sempre que o usuário ou um workflow solicitar a escrita de código de produção para fazer testes passarem.

## Diretrizes de Implementação
* **Código Mínimo:** Escreva estritamente o necessário para o teste passar.
* **Qualidade Estrutural:** Siga os princípios SOLID (indique a aderência em comentários/docstrings).
* **Documentação:** Aplique tipagem explícita (Type Hints) e docstrings estruturadas vinculando à nota do Obsidian (`Ref: Obsidian note [[nome-da-nota]]`).
* **Micro-Checkpoints**: Durante o desenvolvimento, faça o commit das alterações após cada teste. 

## Recursos Disponíveis
* Consulte o manual detalhado em `references/EXECUTION.md` para decisões complexas.
* Use o template de tarefas em `resources/task_template.md` para criar a lista de acompanhamento.
* Siga o padrão de docstring contido em `examples/docstring_example.py`.
* Siga o padrão de commit contido em `examples/commit_example.md`.
